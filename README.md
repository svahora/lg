# LG prototypes

Clickable product prototypes, one folder each. Served at https://svahora.github.io/lg/.

| Prototype | What it shows | Live |
|---|---|---|
| [funboarding](funboarding/) | The compliant framework for crowdfunding onboarding: regulatory requirements, identity verification and structural setup to get fundraisers launch-ready. | https://svahora.github.io/lg/funboarding/ |
| [funboarding-v1](funboarding-v1/) | The earlier version of the onboarding prototype, before the redesign. | https://svahora.github.io/lg/funboarding-v1/ |
| [dash-restructure](dash-restructure/) | A dashboard that lists every fundraiser a user created or helps run, whatever account it pays out to. | https://svahora.github.io/lg/dash-restructure/ |

## Adding a prototype

1. Create a folder with a standalone `index.html` and a `README.md` (what it shows, the live link, what to try).
2. Add a row to the table above and a card to the root `index.html`.
3. Push to `main`. GitHub Pages serves it at `https://svahora.github.io/lg/<folder>/` within a minute or two.
