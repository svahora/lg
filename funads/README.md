# FunAds

A clickable prototype of everything in the self-serve ads v2 build: the admin pages the ads team runs, auto-added fundraisers from approved accounts, the compliance review queue, package sets (a season's packages, dates and sales cap, made live or scheduled), and the creator checkout with card or bank payment.

Live: https://svahora.github.io/lg/funads/

What to try:
- **Creator's fundraiser:** switch between a fundraiser on the seasonal list, one auto-added from an approved account, one on the test list, and one on no list (no offer shown).
- **Buy an ad:** See packages, pick one (Gold is sold out), add details, pay by card or bank. The masjid fundraiser sees 3 tiers; other categories see 4. The details step previews the ad from the fundraiser's own content, with no upload.
- **Three nudges:** a fundraiser on a list gets a page alert, an in-app notification (Notifications) and an email. Each opens packages with its own entry point.
- **Package sets:** create a set from scratch or as a copy, add packages, then make it live or schedule it. "Simulate" jumps to the scheduled date.
- **Season sold out:** open Winter and lower the cap below what's sold, or switch sales off. The creator's page alert, notification and email all disappear.
- **Admin to creator loop:** hide a package or change slots in a set, then go back to the creator checkout.
- **Auto-add:** in Approved accounts, simulate an account creating a fundraiser, then approve or reject it in Compliance review.
- **Requested, not committed:** shows the dashboard Promote button, prefill and the ROI display, marked as requests.
- **Engineering notes:** build notes and open questions on every screen.
- **Data events:** logs the event each action would send, with the shared IDs.

All names, amounts and prices are sample data.
